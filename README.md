# 我的 AI 分身

這個「學員 AI 分身」專案由三個同版本積木組裝而成：

1. `flying-eagle-web-kit`：前端登入、通話與逐字稿介面。
2. `flying-eagle-core-kit`：Auth、Persona、Conversation、共用契約與 LiveKit 入場券。
3. `flying-eagle-voice-kit`：LiveKit Voice Agent、Soniox、OpenAI、MiniMax 與台灣語音處理。

請先閱讀 [積木組裝說明書](course/ASSEMBLY_GUIDE.md)，完成環境變數、測試與自己的 GitHub repository。
